What do you want to do?

Both start from the same place: pairing a device and signing in to Apple. You can switch whenever you like with the buttons in the corner.

Check for an update before starting?

Automatic update checks are off. Timely updates help Apparition keep working when Apple changes its services. Check apparition.illixion.com once for a signed desktop release hosted on GitHub? This does not enable automatic checks or download an update.

Pair this device?
