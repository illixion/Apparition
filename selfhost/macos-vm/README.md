# macOS anisette VM

Apparition can set up a small macOS virtual machine on an Apple silicon Mac and offer its anisette to paired devices. The setup is available in Companion settings or from the command line:

```sh
apparition vm setup
apparition vm status
```

The VM is intended for a Mac that cannot provide anisette directly. Keep it on Apple hardware and pair devices through Apparition's Companion flow. See the main README's Anisette section for supported sign-in options and limitations.
